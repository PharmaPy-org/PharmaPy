# E. coli source documentation and evidence

This package documents the scientific source and the available reproduction
evidence. It does not supply raw experimental observations or establish
independent experimental validation.

## Scientific source

Radhakrishnan Mahadevan, Jeremy S. Edwards, and Francis J. Doyle III (2002).
*Dynamic Flux Balance Analysis of Diauxic Growth in Escherichia coli*.
Biophysical Journal, 83, 1331–1340.
[Original paper](https://doi.org/10.1016/S0006-3495(02)73903-9).

The example targets the qualitative diauxic behavior associated with the paper's
Figure 4 relaxed-flux-rate static-optimization formulation. It is not a
reproduction of every formulation in the paper: the rate-constrained Figure 5
case and full-horizon dynamic optimization are distinct comparisons.

## Included evidence

| File | What it establishes | What it does not establish |
| --- | --- | --- |
| [nested_lp_trajectory.csv](evidence/nested_lp_trajectory.csv) | Frozen trajectory from an earlier implementation; useful for numerical regression | Experimental measurements or an independently digitized published curve |
| [source_manifest.json](../inputs/source_manifest.json) | Source identity, local evidence path, and SHA-256 checksum | Accuracy of the biological assumptions |
| [Current outputs](../outputs/) | Artifacts generated by the native example | Independent validation merely because a check reports PASS |

The CSV was copied unchanged from the reference implementation's
`data/bioreactors/models/mahadevan_ecoli/reference/nested_lp_trajectory.csv`.
Its historical metadata records generation on 2026-09-01, commit
`c95bca6873aed5823e23319b6c0081ed39694cb1`, Python 3.11.15, and Assimulo 3.8.0.
These describe the historical reference, not the current required environment.
No external checkout is needed to read the packaged CSV.

The CSV contains 1,001 time points from 0 to 10 hours. Glucose, acetate, and
oxygen states are concentrations in mmol/L; biomass is in gDW/L. Corresponding
derivatives are per hour and growth rate is in h^-1. The `v1`–`v4` columns use
the historical reduced-pathway normalization; do not assume those columns are
ordinary exchange fluxes in mmol/gDW/h without their coefficient mapping.

## Model inputs and numerical benchmarks

- [case.json](../inputs/case.json): operating configuration and solver settings.
- [mechanism.json](../inputs/mechanism.json): pathway coefficients, bounds,
  initial state, and transport definitions used by this example.
- [thermo.json](../inputs/thermo.json): native phase-property inputs.
- [workflow.ipynb](../workflow.ipynb): native object construction, execution, and reports.

The notebook reads [regression_baseline.json](../inputs/regression_baseline.json),
an explicitly generated current-model baseline, not an experimental endpoint.
It records input SHA-256 values, the Python source-tree digest, package versions,
generation time, command, endpoints, and the unchanged 2% regression threshold.
Normal execution never regenerates or overwrites this baseline. Explicitly
regenerate it with `PYTHONPATH=. python examples/bioreactors/refresh_regression.py`, then
independently rerun the examples and inspect the resulting differences.

The old untraced constant **0.8984192534784751 gDW/L** is retained in the baseline
as historical information. The packaged historical CSV ends at
**0.89841927106952646 gDW/L**. Neither is represented as a measured endpoint.
Updating the software regression baseline does not establish biological accuracy.

The current `balance_audit.json` checks reported-state finiteness and
nonnegativity; its name must not be interpreted as proof of elemental or total
material closure. Constraint residuals, conservation accounting, and numerical
convergence require their own evidence.

## Estimation evidence is separate

[workflow.ipynb](../workflow.ipynb) demonstrates fitting integrated reactor
trajectories using explicitly synthetic measurements and withheld prediction
times. See the [example README](../README.md) and
[estimation configuration](../inputs/estimation.json). Synthetic parameter
recovery is a useful method check, not validation against Mahadevan's raw data.

## Access and limitations

The complete source paper remains linked by DOI. The published comparison panel
from the supplied presentation is now included in [published_figures/](published_figures/README.md),
with extraction provenance. Its inclusion does not relicense the figure under PharmaPy's code license.
No raw experimental trajectory dataset or measured uncertainty accompanies
this package. A quantitative scientific-validation claim would require suitable
independent observations, their provenance and uncertainty, and predeclared
comparison criteria. Copying documentation does not fill that evidence gap.
